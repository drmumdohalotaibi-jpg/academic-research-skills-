# مهارة: تحقيق المذهب عند الأئمة الأربعة

مهارة لـ Claude تُحقّق المعتمد في المسألة الفقهية عند المذاهب الأربعة من كتب المتأخرين، مع العزو والتمييز بين النص والتخريج والخلاف الداخلي.

## الاستعمال
١. حمّل ملف `SKILL.md`.
٢. في claude.ai: الإعدادات ← المهارات ← رفع مهارة.
٣. استدعها بـ `/tahqiq-madhhab-arbaa` أو بطلب «تحقق في المذاهب الأربعة».

## متطلب
تعتمد المهارة على مكتبة **الباحث الذكي** (Al-Bahith) المربوطة بالحساب؛ بدونها تعمل كدليل منهجي فقط.

إعداد: د. ممدوح العتيبي – قسم أصول الفقه، جامعة أم القرى.
